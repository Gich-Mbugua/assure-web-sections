# assure-web-sections

Reusable, performance-optimised HTML, CSS and JavaScript sections for WordPress and Elementor websites.

## Sections

- [Project enquiry form](project-enquiry/README.md) — mobile-responsive briefs for exhibition booths, signage, branding and interior fit-outs, with client-side validation and a copyable WhatsApp summary. Includes a [standalone preview](project-enquiry/demo.html) and [paste-ready Elementor fragment](project-enquiry/elementor.html).

No build step or runtime dependencies. Adding or merging code here does not publish to the live Assure website.
